# Khung chấm điểm sách hoàn chỉnh 📚

---

## 1️⃣ Các tiêu chí chấm điểm (Thang điểm: 100 điểm)

### 1. Nội dung & Giá trị tri thức – 30 điểm

Đánh giá: cuốn sách mang lại **điều gì mới và có ích đến mức nào?**

| Mức   | Mô tả                                                  |
| ----- | ------------------------------------------------------ |
| 25–30 | Rất sâu sắc, nhiều kiến thức/insight mới, áp dụng được |
| 18–24 | Tốt, có giá trị rõ ràng                                |
| 10–17 | Trung bình, ít mới                                     |
| 0–9   | Nghèo nàn, hời hợt                                     |

---

### 2. Tính logic & Cấu trúc – 15 điểm

Đánh giá: bố cục có mạch lạc, dễ theo không?

| Mức   | Mô tả                      |
| ----- | -------------------------- |
| 12–15 | Rất rõ ràng, liên kết chặt |
| 8–11  | Khá tốt                    |
| 4–7   | Hơi rối                    |
| 0–3   | Lộn xộn, khó hiểu          |

---

### 3. Cách trình bày & Văn phong – 15 điểm

Đánh giá: dễ đọc, cuốn hút hay khô khan?

| Mức   | Mô tả                            |
| ----- | -------------------------------- |
| 12–15 | Mạch lạc, sinh động, dễ tiếp thu |
| 8–11  | Ổn                               |
| 4–7   | Khó đọc                          |
| 0–3   | Rất khó chịu khi đọc             |

---

### 4. Tính thực tiễn – 15 điểm

Đánh giá: có **áp dụng được vào đời sống/công việc không?**

| Mức   | Mô tả                     |
| ----- | ------------------------- |
| 12–15 | Áp dụng rõ ràng, hiệu quả |
| 8–11  | Có ích nhưng cần chọn lọc |
| 4–7   | Khó áp dụng               |
| 0–3   | Gần như không dùng được   |

---

### 5. Độ tin cậy & Dẫn chứng – 10 điểm

Đánh giá: luận điểm có cơ sở không?

| Mức  | Mô tả                    |
| ---- | ------------------------ |
| 8–10 | Dẫn chứng mạnh, đáng tin |
| 5–7  | Khá                      |
| 2–4  | Yếu                      |
| 0–1  | Thiếu căn cứ             |

---

### 6. Giá trị cảm xúc / Trải nghiệm đọc – 10 điểm

Đánh giá: mức độ hứng thú và ấn tượng sau khi đọc.

| Mức  | Mô tả                   |
| ---- | ----------------------- |
| 8–10 | Rất cuốn, để lại dấu ấn |
| 5–7  | Dễ chịu                 |
| 2–4  | Nhạt                    |
| 0–1  | Khó chịu, chán          |

---

### 7. Tính độc đáo – 5 điểm

Đánh giá: có khác biệt so với các sách cùng chủ đề không?

| Mức | Mô tả         |
| --- | ------------- |
| 4–5 | Rất mới       |
| 2–3 | Khá           |
| 0–1 | Cũ, trùng lặp |

## 2️⃣ Cách tính điểm cuối cùng

**Tổng điểm = cộng tất cả các mục (tối đa 100).**

### Gợi ý xếp hạng:

| Điểm   | Đánh giá           |
| ------ | ------------------ |
| 90–100 | Xuất sắc – nên đọc |
| 75–89  | Rất tốt            |
| 60–74  | Tốt                |
| 45–59  | Trung bình         |
| < 45   | Không khuyến nghị  |

## 3️⃣ Mẫu ghi nhanh sau khi đọc

Bạn có thể dùng form này:

```
Tên sách:
Tác giả:

1. Nội dung: ___ /30
2. Logic – cấu trúc: ___ /15
3. Văn phong: ___ /15
4. Thực tiễn: ___ /15
5. Độ tin cậy: ___ /10
6. Trải nghiệm đọc: ___ /10
7. Độc đáo: ___ /5

TỔNG: ___ /100

Nhận xét ngắn:
- 3 ý chính rút ra:
- Có nên đọc lại/giới thiệu không:
```
